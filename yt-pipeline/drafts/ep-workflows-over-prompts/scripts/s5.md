# S5 — Schemas as Ledgers: Contracts Between Pipeline Stages | targetWords: 170 | keywords: structured outputs, JSON schema contract, constrained decoding, agent handoffs, task ledger, Magentic-One, schema validation agents

Amnesia only works if every handoff is written down. A JSON schema isn't formatting — it's the contract that lets stage two trust stage one without re-reading its work. Adherence is engineering, not a model property: GPT-4's June 2023 checkpoint scored under forty percent on complex schemas, trained GPT-4o hit ninety-three, constrained decoding closed it to one hundred — riding a newer model, granted. Anthropic's structured outputs, generally available for Fable 5, compile schemas into token-constraining grammars: no parse errors, no schema-violation retries, grammars cached twenty-four hours. The Claude Agent SDK extends the JSON schema contract across multi-turn runs: tools mid-run, validated JSON at the end — failure is typed, never free-text garbage. Microsoft's Magentic-One keeps two ledgers: a Task Ledger of facts and plans, a per-step Progress Ledger. Stall counter past two? Re-plan from the ledger. OpenAI's SDK makes agent handoffs typed tool calls: Refund Agent becomes transfer to refund agent, Pydantic-validated before the callback fires. The JSON-hurts-reasoning objection didn't replicate: prompts held equal, structured matched or beat free-form — GSM-8K, point seven eight versus point seven seven. XGrammar makes schema validation for agents near-free, up to one hundred times faster. The contract is cheap. Re-reading stage one is not.
