# S8 — Takeaway: Make It Legible and Enforceable | targetWords: 150 | keywords: agent harness design, legible and enforceable, AI agent half-life, bounded work block, outcome rubric, workflows over prompts takeaway

When OpenAI's harness team hit failures, the fix was almost never "try harder" — because the prompt is not the program; the workflow is. Engineers asked: what capability is missing, and how do we make it both legible and enforceable for the agent? That's the workflows over prompts takeaway: agent harness design. Project Vend, phase one: Claudius lost money. Phase two's most impactful change: forcing Claudius to follow procedures. Weeks with negative profit margin largely eliminated — now running in three cities. The intelligence-shaped fix, a CEO supervisor agent, had a mixed, possibly negative effect. Toby Ord, on METR's data: the AI agent half-life is measurable — a constant per-minute failure rate, success decaying exponentially with task length. Structure moves the exponent. Mitch Ashley at Futurum: delegate a bounded work block the agent owns end to end, not a prompt. Anthropic agrees: define done as a gradeable outcome rubric — iterate, grade, revise, default three iterations, max twenty. Make the missing capability legible. Make it enforceable. Anthropic says Fable 5 can work for days — and now you know which word in that sentence is load-bearing. The harness.
