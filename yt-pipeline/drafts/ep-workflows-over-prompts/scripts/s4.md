# S4 — Compiled Control Flow: /loop, /goal, and the Ralph Lineage | targetWords: 170 | keywords: ralph loop, ralph wiggum technique, Codex goal mode, stop hook loop, Geoffrey Huntley, context rot, fresh context agents

Three vendors just compiled the same technique into their agent products: one line of bash that throws the model's memory away on purpose. Geoffrey Huntley named it Ralph: a bash loop — cat PROMPT dot md into claude code, forever. The ralph loop discards conversation history by construction. Every iteration re-feeds four locked files: PROMPT, the fix plan, the specs, and AGENT dot md, which Ralph self-updates with learnings. Git commits and the codebase are the external memory. Huntley's self-reported math: a fifty-thousand-dollar contract delivered for two hundred ninety-seven dollars; six repos shipped overnight. The rule: one item per loop, because output quality clips between one hundred forty-seven and one hundred fifty-two thousand tokens. Chroma's context rot study tested eighteen models: focused three-hundred-token prompts beat one-hundred-thirteen-thousand-token full prompts on every one. The ralph wiggum technique became a first-class primitive. Anthropic's official plugin runs a stop hook loop that blocks session exit, capped by max iterations, with a hard stop after eight consecutive blocks. Codex goal mode ships a verifiable stopping condition. Gemini's extension thanks Huntley by name. Fresh context agents won. The amnesia was the feature.
