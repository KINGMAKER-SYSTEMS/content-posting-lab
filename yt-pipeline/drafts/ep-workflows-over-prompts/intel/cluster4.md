## Cross-cutting takeaways for the ABN episode

1. **The topic is validated and HOT.** All three covered harness engineering and /loop//goal-style compiled autonomy in the last 3 months (Jason Mar 5 + May 9, Dan continuously, David May–Jun). "Harness engineering" has crossed from OpenAI blog jargon into creator vocabulary — assume our audience has heard the term; don't introduce it like it's new, *advance* it.
2. **Nobody owns the precise thesis.** All three say "workflows/harness matter." None has done the head-to-head: programmatically LOCKED values (orchestration scripts, JSON schemas as contracts/ledgers, deterministic control flow) **vs** prompt-tuning, argued with evidence. That exact framing is open territory.
3. **Receipts are our edge.** Dan shows demos, Jason shows diagrams, David shows vibes. ABN can show a *production ledger*: our own factory's JSON contracts, orchestration scripts, and deterministic assembly — "we run a daily show on this principle" is a claim none of them can make.
4. **Format gap.** Dan = 30–50 min weekly; Jason = 10–20 min sporadic; David = daily but unfocused hype. **Daily + 10–14 min + engineering-grade argument** is an unoccupied quadrant.
5. **Hook craft to steal:** stat-shock cold open with a precise number (Dan: "130,000 reviews… $1"), evidence-stack-then-question (Jason: 3 proofs + authority quote in 25s), stakes ladder + roadmap (David). For this episode: open with a concrete locked-vs-tuned failure/success number, then pose "why does the script beat the prompt?"
6. **Title register options seen working:** ALL-CAPS power word (Dan), obituary declarative ("X is dead / Anthropic killed X" — Jason's 206K-view best), "Don't do X… do this instead" (David). A natural fit: "Stop Tuning Your System Prompt" / "Your System Prompt Is Not the Product — the Workflow Is."
7. **Naming watch (for script accuracy):** current ecosystem terms appearing across their titles: Pi coding agent, Hermes Agent (/goal), OpenAI Codex /goal + Symphony, Ralph loop 2.0, Claude Code Agent Teams, GPT-5.5, Opus 4.7, Fable 5, Claude MYTHOS. Cite vendor features precisely.
